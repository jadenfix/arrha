# Arrha / Aether project context

Read [README](README.md), [architecture](docs/architecture.md),
[testing](docs/testing.md), and [contributing](CONTRIBUTING.md).
Rust package and binary names still use Aether.

## Current implementation

The binary assembles JSON-RPC, a mempool, VRF/HotStuff/BLS consensus, sequential
ledger execution with Wasmtime contracts, libp2p/TCP networking, finalized
RocksDB persistence, and Prometheus metrics. Parallel scheduler, QUIC/Turbine,
AI service/verifier libraries, and the local firehose/indexer are separate
components. Do not claim their presence is end-to-end node integration.

## Commands

```bash
cargo build --workspace
./scripts/lint.sh
./cli-test
./cli-test --in-process-only
npm ci && npm run build:web
./scripts/devnet.sh start
./scripts/devnet.sh stop
```

MSRV is 1.86. Test policy is E2E-only. Keep benchmark/fuzz work separate and do
not restore removed unit/property/doctest or JS/Python test runners.

## Operator boundaries

Preserve keys, secrets, active processes, and other contributors' changes.
Do not read credential files, force-push, publish packages, or apply remote
infrastructure without authorization. Local devnet keys are generated by the
launcher and are not production credentials.

The optional autonomous crew uses [AGENT_COMMS.md](AGENT_COMMS.md) for review
coordination and [PROGRESS.md](PROGRESS.md) for handoff notes. Existing peer/domain/
crypto/final review ownership still applies to that crew. Use the current
[task list](TASKS.md); stale five-agent task snapshots have been replaced.
